Installer le module local

Le module (yt-dlp + ffmpeg) permet de télécharger YouTube et des milliers d'autres sites, en MP4 ou en MP3. Il s'installe une seule fois.

État du module

Vérification…

Windows

  1. Installez Python 3 depuis python.org (cochez « Add python.exe to PATH ») ou depuis le Microsoft Store.
  2. Téléchargez le projet : archive .zip du dépôt GitHub, puis décompressez-la.
  3. Ouvrez le dossier helper et double-cliquez sur install-windows.bat.
  4. Pour YouTube, installez Deno : 
    winget install DenoLand.Deno
  5. Redémarrez Chrome.

macOS / Linux

  1. Vérifiez que Python 3.9 ou plus est installé : python3 --version.
  2. Dans le dossier helper du projet : 
    sh install.sh
  3. Pour YouTube, installez Deno : 
    brew install deno            # macOS
curl -fsSL https://deno.land/install.sh | sh   # Linux
  4. Redémarrez Chrome.

Bon à savoir

  • Les fichiers vont dans Téléchargements/Capteur video.
  • Si YouTube change et que le téléchargement échoue, relancez l'installateur : il met yt-dlp à jour.
  • Désinstallation : python install.py --uninstall.
