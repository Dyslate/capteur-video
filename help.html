Install the local helper

The helper (yt-dlp + ffmpeg) downloads YouTube and thousands of other sites, and unlocks the MKV, FLAC and Opus formats. It is a one-time install.

Windows

  1. Install Python 3 from python.org and tick “Add python.exe to PATH”.
  2. Open the extension folder, the one you picked in chrome://extensions (for example Downloads\capteur-video).
  3. Double-click install-helper.bat, right next to manifest.json. It takes one to three minutes.
  4. For YouTube, install Deno (in a terminal): 
    winget install DenoLand.Deno
  5. Restart Chrome, then click “Check again” above.

You don't have the folder? Download the project archive, unzip it, and load that folder in Chrome.

macOS / Linux

  1. Check that Python 3.9 or later is installed: python3 --version.
  2. In the extension folder: 
    sh helper/install.sh
  3. For YouTube, install Deno: 
    brew install deno                              # macOS
curl -fsSL https://deno.land/install.sh | sh   # Linux
  4. Restart Chrome.

Good to know

  • Files saved by the helper go to Downloads/Capteur video.
  • If a site changes and downloads start failing: “Update yt-dlp” above, or run install-helper.bat again.
  • Uninstall: install-helper.bat --uninstall (in a terminal), or python helper/install.py --uninstall.

  • If something goes wrong: open the log, click “Copy” and send it.
