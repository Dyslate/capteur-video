Test lab

Synthetic media (test pattern + beep, generated by ffmpeg) to test every kind of stream without relying on a real site.

  1. Open the extension's side panel (Capteur vidéo icon).
  2. Open a scenario below, then look at the card that shows up in the panel.
  3. Download it in several formats and qualities.
  4. Run verify.bat (or python verify.py): it checks every downloaded file (tracks, duration, codec, decoding errors).
  5. If something fails: panel → Log → “Copy”, plus the output of verify.py.

Scenarios

01 Direct MP4
A complete MP4 file (H.264 + AAC, 1280×720, 8 s) played by a <video> element.
02 WebM (VP9 + Opus)
A 640×360 WebM file played by a <video> element.
03 HLS with TS segments, two qualities
An HLS master playlist (720p and 360p) with .ts segments, loaded the way a player would.
04 HLS with fMP4 segments
An HLS playlist whose segments are fragmented MP4 (init.mp4 + .m4s).
05 DASH, separate video and audio
A DASH manifest (SegmentTemplate) with video in 720p and 360p, and audio on its own.
06 Split tracks (Instagram style)
Like on Instagram: video and sound are two separate files, requested in chunks with <code>bytestart</code>/<code>byteend</code> and identified by an <code>efg</code> parameter.
07 Manifest hidden in the page
Nothing loads by itself: the DASH manifest is hidden in the page's JSON data, like on some Instagram pages.
08 Audio only
An M4A (AAC) file played by an <audio> element.
09 Encrypted streams (must be refused)
An encrypted HLS stream (AES-128) and a protected DASH stream (ContentProtection).
10 Page for the yt-dlp helper
A regular page with a video: used to test the “Whole page with yt-dlp” card.
