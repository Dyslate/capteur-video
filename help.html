Installer le module local

Le module (yt-dlp + ffmpeg) permet de télécharger YouTube et des milliers d'autres sites, en MP4 ou en MP3. Il s'installe une seule fois.

Vérification…

Windows

  1. Installez Python 3 depuis python.org en cochant « Add python.exe to PATH ».
  2. Ouvrez le dossier de l'extension, celui que vous avez choisi dans chrome://extensions (par exemple Téléchargements\capteur-video).
  3. Double-cliquez sur installer-module.bat, juste à côté de manifest.json. Comptez une à trois minutes.
  4. Pour YouTube, installez Deno (dans un terminal) : 
    winget install DenoLand.Deno
  5. Redémarrez Chrome, puis cliquez sur « Revérifier » ci-dessus.

Vous n'avez pas le dossier ? Téléchargez l'archive du projet, décompressez-la, et chargez ce dossier dans Chrome.

macOS / Linux

  1. Vérifiez que Python 3.9 ou plus est installé : python3 --version.
  2. Dans le dossier de l'extension : 
    sh helper/install.sh
  3. Pour YouTube, installez Deno : 
    brew install deno            # macOS
curl -fsSL https://deno.land/install.sh | sh   # Linux
  4. Redémarrez Chrome.

Bon à savoir

  • Les fichiers vont dans Téléchargements/Capteur video.
  • Si un site change et que le téléchargement échoue : bouton « Mettre à jour yt-dlp » ci-dessus, ou relancez installer-module.bat.
  • Désinstallation : installer-module.bat --uninstall (dans un terminal), ou python helper/install.py --uninstall.
